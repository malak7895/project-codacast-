# VELORA E-Commerce Frontend Storefront

A modern, responsive multi-page e-commerce website designed specifically for fashion and clothing collections. Built cleanly from scratch using foundational web technologies to deliver a smooth and elegant user experience.

## Key Features:
* **Multi-Page Architecture:** Includes structured pages for Home (`index.html`), Women (`women.html`), Men (`men.html`), Collections (`collection.html`), Sales (`sale.html`), and Contact (`contact.html`).
* **Interactive UI Elements:** Dynamic navigation, search utilities, user account options, and shopping cart indicators powered by custom JavaScript (`script.js`).
* **Modern Styling:** Styled completely with custom CSS (`style.css`) emphasizing clean layouts, high-quality seasonal hero sections, and elegant typography.
* **Responsive Design:** Optimized for seamless viewing across various device screens.

## Technologies Used:
* **HTML5** (Structuring semantic layouts)
* **CSS3** (Styling, layouts, and visual design)
* **JavaScript** (Client-side interactivity and logic)
